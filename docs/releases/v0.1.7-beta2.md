# vLLM-SM75 v0.1.7 beta2

统一 `vllm-sm75:v0.1.7-ultra-beta2`，保留 Flash Next 与原有 27B 支持。

- 增加 27B FP8 / NVFP4＋DSpark k5 模板，完善 FP8 KV、256K 上下文和 CPU KV 启动检查。
- Ultra 内置 BenchLocal 九类测试及全部执行依赖，支持默认六项、参数调整、逐题结果、雷达图和数据导入导出；只需构建一个 Ultra 镜像。
- 完善运行配置的创建、切换和删除，优化 API 地址 / Key 复制、监控统计及界面显示。
