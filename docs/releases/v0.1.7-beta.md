# vLLM-SM75 v0.1.7 beta

2026-10-05 预发布。统一镜像 `vllm-sm75:v0.1.7-ultra-beta` 支持原有 Qwen3.8 27B 与 Flash Next，完整 Docker 参数和 Ultra 面板共用模型模板。

- **Flash Next**：整合 W4A16 / FP8 PLE、QSA、FP8 KV、PLE投影驻留GPU及MTP适配。提供TP8无MTP/MTP3模板，支持256K单路和并发4混合负载。
- **性能优化**：按请求分组执行QSA，改善长Prefill影响短请求Decode的问题。8K实测Prefill/Decode分别为无MTP **3225.82/49.93**、MTP3 **3127.89/69.86 tok/s**；混合负载同进程A/B总吞吐分别提升 **71.56%/70.01%**。单路约50是当前能力确认值，不作为本轮新增优化收益。
- **原有模型**：保留27B FP8/AWQ、MTP/DFlash2、Firefly、CPU KV、监控和电源管理；Next专用设置按模型隔离。
- **Ultra修复**：包含beta Debug的初始化/切换恢复、API Key同步、配置保存后列表刷新、外观恢复及Prefill/Decode计时修复。
- **统一启动**：同一镜像默认提供1615面板；仅API运行设置 `SM75_EDITION=standard`，模型兼容和推理能力共用。

实测条件为8×Tesla T10；8K预热后正式3次取中位，混合负载为1K/8K/16K/32K各输出256。长文本单点、MTP内容差异及27B历史回归范围见下方验证文档。
